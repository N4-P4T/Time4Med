# Time4Med — แจ้งเตือนพร้อมลิงก์เว็บไซต์ (ทดสอบด้วย TEST_ เท่านั้น)

สเปก LINE ที่ตกลงกัน: การแจ้งเตือนผู้ดูแลต้องมี **ข้อความบอกเวลาและผู้สูงอายุ** และ **ลิงก์เว็บไซต์ Time4Med ให้กดได้ทันที** ไม่ใช่ข้อความลอย ๆ

ไฟล์ [ReminderLink.gs](./ReminderLink.gs) ใช้เว็บไซต์:
https://n4-p4t.github.io/Time4Med/

ลิงก์นี้คือ root ของ GitHub Pages จากไฟล์ `index.html` ที่ปัจจุบันเปลี่ยนเส้นทางไป `test-v021/` เพื่อไม่ผูกกับชื่อรุ่นเว็บไซต์ที่อาจเปลี่ยนในอนาคต

## ข้อความใน LINE

ข้อความมี:
- หัวข้อ `[Time4Med] แจ้งเตือนมื้อยา`
- รหัสผู้สูงอายุ `P001`, `P002`, หรือ `P003`
- เวลาตามตาราง
- URL จริงที่กดหรือคัดลอกได้จากข้อความ
- ปุ่ม **เปิดเว็บไซต์** (LINE URI Quick Reply) เปิดในเบราว์เซอร์ของ LINE
- ข้อความเตือนว่าเป็นการทดสอบอย่างชัดเจนเมื่อใช้ข้อมูล `TEST_*`

ไม่แนบ Token, LINE user ID, ชื่อยา, ข้อมูลสุขภาพ หรือข้อมูลชื่อจริงผ่าน URL; เว็บไซต์ต้องบังคับ Sign-In และตรวจสิทธิ์ผู้ดูแลเอง

## วิธีทดลองแบบปลอดภัย — ส่งเพียงหนึ่งข้อความ

ข้อกำหนด: โปรเจกต์ Google Apps Script เดิม `Time4Med_LINE_Pilot` มี `Code.gs`, `SheetPreview.gs`, `SheetLineDemo.gs` อยู่แล้ว และทดสอบส่ง LINE ถึงเจ้าของสำเร็จแล้ว

1. เพิ่มไฟล์ Script ใหม่ชื่อ `ReminderLink` แล้ววางโค้ด [ReminderLink.gs](./ReminderLink.gs) ทั้งหมด กด Save
2. เลือก `previewLinkedReminderDemo` แล้ว Run; ตรวจว่าผลมี `messageSent:false`, `website:"https://n4-p4t.github.io/Time4Med/"`, และข้อความมี `TEST`
3. เมื่อพร้อมจึงไป Project Settings → Script properties เพิ่ม `LINE_LINK_TEST_CONFIRM` เป็น `YES` (ค่านี้แยกจากการทดสอบเดิม)
4. เลือก `sendLinkedReminderDemoOnce` แล้ว Run **เพียงครั้งเดียว**
5. ตรวจแชต Time4Med ว่ามี **ลิงก์เว็บไซต์ในข้อความ** และปุ่ม **เปิดเว็บไซต์** กดแล้วไปยังหน้า Time4Med ที่เปิดผ่าน Google Sign-In ได้
6. ถ้า Error ห้าม Run ซ้ำหรือลบ `LINE_LINK_TEST_STATE` เอง; บอก Error ให้ตรวจสอบก่อน
7. หลังส่งเสร็จตั้ง `LINE_LINK_TEST_CONFIRM=NO` ได้ โดยเก็บ `LINE_LINK_TEST_STATE` เป็นหลักฐาน

## ทำไมยังไม่ส่งเตือนอัตโนมัติ

จากฐานข้อมูลปัจจุบัน `MealMedicines` มี active 2 รายการ และทั้งสองรายการเป็นข้อมูล `TEST_*` จึงยังไม่มีมื้อยาจริงที่ผ่านเงื่อนไข และผู้ดูแลใน `Users` ยังไม่พร้อมครบทุกคน

`ReminderLink.gs` เป็น **ตัวสร้างข้อความที่มีลิงก์** และฟังก์ชันทดสอบครั้งเดียว ไม่ได้สร้าง Trigger และไม่สั่งให้ผู้สูงอายุรับประทานยาจริง

**เมื่อมีรายการยาจริงและสิทธิ์ผู้ดูแลที่ตรวจแล้ว** ค่อยสร้างรอบตรวจเวลา Asia/Bangkok, ledger/idempotency ป้องกันส่งซ้ำ และเรียกตัวสร้างข้อความนี้จากโปรแกรมส่งอัตโนมัติ
