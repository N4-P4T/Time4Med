# Time4Med — ปรับการจัดการรหัสผ่าน MQTT (ชั่วคราว)

## เหตุผล

GitHub Pages เป็นเว็บแบบ static: ทุกอย่างใน HTML/CSS/JS รวมทั้งไฟล์ \`mqtt-config.js\`
อ่านได้โดยผู้ใช้งานอินเทอร์เน็ต จึงห้ามเก็บรหัสผ่าน HiveMQ หรือรหัสควบคุมกลอนลงไฟล์ดังกล่าว

## การแก้ไขชุดนี้

- เอา \`password\` ออกจาก \`mqtt-config.js\`
- ผู้ดูแลคลิกสถานะ MQTT เพื่อเปิด dialog ใส่รหัสผ่านเฉพาะ **แท็บที่เปิด**
- ไม่บันทึกรหัสใน \`localStorage\`, \`sessionStorage\`, cookies หรือไฟล์เว็บไซต์
- ล้างค่าใน input หลังส่ง; ปิด/รีโหลดหน้าเว็บต้องกรอกใหม่
- การเชื่อมต่อ Broker ยังคงใช้ WSS/TLS; ไม่แก้คำสั่ง LOCK/UNLOCK เดิม
- เพิ่ม browser test แบบ offline ทั้งหมด ไม่เชื่อมต่อ HiveMQ จริง

> ข้อจำกัด: ผู้ที่มีสิทธิ์ใช้บัญชี MQTT ในหน้าเว็บยังสามารถเปิด Developer Tools
> และส่งคำสั่งตามสิทธิ์ที่บัญชีนั้นมีได้ การเก็บรหัสในหน่วยความจำชั่วคราว
> ไม่ได้ทำให้การสั่งกลอนปลอดภัยเพียงพอสำหรับการเปิดใช้งานสาธารณะ

## สิ่งที่ต้องทำใน HiveMQ ก่อนเผยแพร่

1. **เปลี่ยนและเพิกถอนรหัสเก่า** ที่เคยฝังในเว็บไซต์
2. ตรวจ access rights / ACL ของบัญชี \`time4med-web\` ให้ต่ำที่สุด
3. ควรใช้ authenticated backend เช่น Cloudflare Workers + ตรวจสิทธิ์ Google Sign-In
   ก่อนส่งคำสั่งควบคุมกลอน ไม่เปิดสิทธิ์ตรงจากเบราว์เซอร์ในระยะยาว
4. ตรวจ Git History และข้อมูลลับที่หลุดก่อนหน้านี้: ลบจากไฟล์ล่าสุดอย่างเดียว
   **ไม่ได้ลบจากประวัติการ Commit**

ระบบอาจต้องกรอกรหัสทุกครั้งที่เปิดหน้าใหม่จนกว่าจะทำระบบ gateway ที่ปลอดภัย
ห้าม Merge โดยไม่ได้วางแผนย้ายบัญชีและทดสอบในสภาพแวดล้อมทดลอง
