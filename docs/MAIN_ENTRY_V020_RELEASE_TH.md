# เปลี่ยนลิงก์หลัก Time4Med เป็น Google Dashboard v0.20

การเผยแพร่ชุดนี้เปลี่ยนเฉพาะหน้าแรก `index.html` ให้เข้าสู่ `/Time4Med/test-v020/`
โดยยังคงรูปแบบ Google Sign-In จาก v0.19 และแดชบอร์ดแยกหน้าอุปกรณ์จาก v0.20

## ผลกระทบ

- ผู้เปิด `https://n4-p4t.github.io/Time4Med/` จะถูกส่งไป `test-v020/`
- หน้าเว็บที่ยืนยันตัวตนแล้ว **ไม่เชื่อม MQTT ไปยังกลอนโดยตรง**
  การควบคุมระยะไกลยังไม่พร้อมใช้งานผ่านระบบใหม่จนกว่าจะมี authenticated backend gateway
- โค้ดเฟิร์มแวร์ที่อยู่บน ESP32-S3 ไม่เปลี่ยน
- ไฟล์ `mqtt-config.js` บน GitHub จะไม่มี password field อีกต่อไป
- ชื่อผู้ใช้และ URL MQTT ไม่ถือเป็น secret; password เดิม **ยังปรากฏได้ใน Git history**
- ต้อง **rotate/revoke password เดิมใน HiveMQ** ก่อนเริ่มใช้จริง และกำหนด ACL แยก web/device
- หน้า `test-v019/` ยังเปิดทดสอบแยกได้; Git history ยังคงมีหน้าเดิมสำหรับการแก้ไขย้อนกลับ
- ไม่สร้างหน้า Legacy ที่คัดลอกรหัสผ่านเก่าขึ้นมาเผยแพร่อีก

## วิธีตรวจ

เปิดลิงก์หลัก (หลัง GitHub Pages Deploy: success) แล้วควรเข้าสู่หน้า Google Sign-In ของ v0.20
ถ้าสำเร็จหลัง Google ลงชื่อเข้าใช้ จะเห็นแดชบอร์ดสรุปมื้อยาที่โหลดได้
แต่ยังไม่มีสถิติรับยาที่ตรวจสอบครบถ้วนหรือการควบคุมกลอนจนกว่า Backend จะพร้อม

## กลับไปยังเวอร์ชันก่อนหน้า

หากจำเป็น ให้ revert เฉพาะ commit ที่เปลี่ยนหน้าแรกหลังตรวจ
โดยรักษา `mqtt-config.js` แบบไม่มี secret ไว้ และ **ห้ามนำรหัส HiveMQ เดิมกลับขึ้นเว็บไซต์**
ไม่แนะนำให้ restore เว็บเดิมที่สามารถสั่งกลอนตรงจาก Browser ก่อนระบบตรวจสิทธิ์พร้อม
