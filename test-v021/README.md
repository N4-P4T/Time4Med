# Time4Med Caregiver Center v0.21

หน้า Dashboard ที่ออกแบบสำหรับผู้ดูแลและการเก็บภาพประกอบรายงานโครงงาน

- ใช้ Google Sign-In และ Backend เดิมจาก test-v019 และ script.js ของ test-v020
- ส่วนหัวเล็กลงและแสดงข้อมูลภาพรวมได้โดยไม่ต้องเลื่อนมาก
- สรุปผู้สูงอายุที่บัญชีนี้ได้รับอนุญาตจาก /api/patients, จำนวนรายการยาตามเวลา, รอบยาถัดไป และรายการข้อมูลรอตรวจ
- การ์ดรายคนแสดงชื่อ/รหัสผู้สูงอายุ หมายเลขกล่อง จำนวนรายการยาตามเวลา และรอบยาถัดไป
- ข้อมูลยาจาก Google Sheets เมื่อ Backend ส่งข้อมูลและการซิงก์สำเร็จ; สถานะเครื่องไม่ถือว่าออนไลน์จนกว่าจะมี Gateway
- สถิติรับยา, Timeline, เสียงและการแจ้งเตือนฉุกเฉินยังแสดงรอข้อมูลจนกว่าจะมี Backend ที่ตรวจสอบได้
- ปุ่มสั่งกลอนยังไม่เปิดทำงานผ่าน Browser ใน Secure Mode

การแคปลงรายงาน: เปิดด้วยบัญชีที่ได้รับสิทธิ์และรอข้อมูลโหลดครบ ใช้ข้อมูลจริงหรือข้อมูลทดสอบที่ระบุว่าเป็นข้อมูลทดสอบ หลีกเลี่ยงเผยข้อมูลส่วนบุคคล อย่านำภาพหน้าจอจำลองในการทดสอบ GitHub Actions ไปกล่าวว่าเป็นผลทดสอบอุปกรณ์จริง

ห้ามตีความว่าเพียงกดปุ่มยืนยันเท่ากับกลืนยาแล้ว
